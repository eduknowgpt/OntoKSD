a OntoKSD contém uma Taxonomia revisada de Bloom atualizada com verbos de computação (fiz uma representação ontológica da mesma), Vocabulários de Conhecimentos de computação (CC2020, ACM CCS2012 e CC2013 Body of Knowledge), vocabulário de conhecimentos profissionais (alinhados ao CC2020), vocabulário de Disposições (alinhados ao CC2020). Ou seja, a OntoKSD dá suporte à especificação de Conhecimentos, Disposições e Habilidades (via Bloom). 

Crie um diagrama para um processo com 4 etapas:

Competency Specification Process (CSP)

1. Task Description Analysis
    Input: Task Description (Text file)
    Output: Structured Task Representation

2. Knowledge Enumeration
    Input: OntoKSD Knowledge Vocabulary
    Output: Task-Specific Knowledge Enumeration

3. Learning Objectives Identification
    Input: Task Description (Text file)
    Output: Task-Related Learning Objectives Enumeration

4. Competency Definition
    Inputs:
      Task-Specific Knowledge Enumeration
      Task-Related Learning Objectives Enumeration
      Select OntoKSD Disposition Vocabulary
	Process:
		Map Competence Knowledge-Skill
			Use OntoKSD Bloom Taxonomy
				Suggested Verbs
		Insert or Reuse Competence (Search OntoKSD)
    Output: List of Structured Competencies 




4.1 Competency Title and Identifier
 Input: Learning Objective
 Output: Competency Title and Unique Identifier

4.2 Competency Textual Description
 Input: Learning Objective, Task Context
 Output: Detailed Competency Description (scope, relevance, purpose)

4.3 Knowledge Specification
 Input: Task-Specific Knowledge Enumeration
 Output: List of Knowledge Elements associated with the Competency

4.4 Disposition Specification
 Input: OntoKSD Disposition Vocabulary
 Output: List of Required Dispositions for the Competency

4.5 Knowledge–Skill Mapping and Cognitive Alignment
 Inputs:
   Knowledge Elements
   OntoKSD Bloom Taxonomy
 Outputs:
   Knowledge–Skill Pairs
   Bloom Taxonomy Level associated with each skill
   Action Verb Annotation for each skill
   Suggested Update or Reuse of Competence (Search OntoKSD)
