
Competency C-001 Task 1: 

Document User Requirements

Instructions:
You are part of a team tasked with developing a new library management system. Conduct a mock interview with a stakeholder (such as a librarian) to gather requirements. Document at least five key system requirements based on this interaction.

Example Output:
1. The system should allow librarians to add new books to the inventory.
2. The system should enable users to search for books by title, author, or genre.
3. The system should provide a checkout feature for borrowing books.
4. The system should keep track of overdue books and notify users.
5. The system should generate monthly reports on book loans and returns.




Competency C-001 Task 2: 
Create a Requirements Specification Document

Instructions:
Using the requirements gathered from the mock interview, create a simple requirements specification document. Ensure that the document is clear and structured, including sections such as Introduction, Functional Requirements, and Non-Functional Requirements.

Example Output:
Requirements Specification Document
1. Introduction
   This document specifies the requirements for the new library management system.

2. Functional Requirements
   2.1 The system should allow librarians to add new books to the inventory.
   2.2 The system should enable users to search for books by title, author, or genre.
   2.3 The system should provide a checkout feature for borrowing books.
   2.4 The system should keep track of overdue books and notify users.

3. Non-Functional Requirements
   3.1 The system should be user-friendly and intuitive.
   3.2 The system should be accessible on various devices, including desktops and tablets.

Instructions:
Identify three cloud service models (IaaS, PaaS, SaaS). Create a table comparing their key features, benefits, and potential drawbacks.

Example Output:
| Cloud Service Model | Key Features                             | Benefits                                    | Potential Drawbacks                   |
|---------------------|------------------------------------------|---------------------------------------------|---------------------------------------|
| IaaS                | Virtualized computing resources          | Flexibility, scalability, pay-as-you-go     | Requires management of infrastructure |
| PaaS                | Platform for building and deploying apps | Simplified development, managed infrastructure | Less control over underlying hardware |
| SaaS                | Software delivered over the internet     | Accessibility, minimal maintenance          | Limited customization options         |





Competency C-002 Task 2:
Cost-Benefit Analysis of Cloud Services

Instructions:
Perform a simple cost-benefit analysis for moving an organization's email services to a cloud-based solution (SaaS). Identify at least three benefits and three costs associated with this transition.

Competency Elements:
Knowledge-Skill Pair 1: Enterprise Architecture - Analyzing
Knowledge-Skill Pair 2: IS Management and Leadership - Evaluating
Knowledge-Skill Pair 3: Written Communication - Applying

Dispositions:
Proactive
Self-directed
Professional

Example Output:
Cost-Benefit Analysis: Cloud-based Email Services

Benefits:
1. Reduced IT maintenance costs.
2. Increased accessibility and collaboration.
3. Scalability to accommodate business growth.

Costs:
1. Subscription fees for cloud service.
2. Data migration expenses.
3. Potential downtime during transition.
