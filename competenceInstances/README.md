## Select before loading

1. Identify the dataset's source and interpretation notes.
2. Load the ontology and required imports/vocabularies.
3. Choose insertion scripts or the corresponding Turtle snapshot where provided; do not load both as independent sources.
4. Record dataset selection, inference settings, and parameters.
5. Compare answers with dataset-specific expectations when available.

Curricular examples describe expectations. Historical assessment encodings organize available records. Fictional examples and fixtures exercise the model. These have different evidential roles.
