# Explore a Moodle projection

These CSV files illustrate selected specification content organized as a Moodle competency framework and associated scale. They are an operational entry point, not a complete OWL synchronization service.

| Files | Purpose |
| --- | --- |
| [Framework](ontoksd_competency_framework.csv) · [Scale](moodle_scale_0_100_with_intervals.csv) | English examples. |
| [Portuguese framework](ontoksd_competency_framework_pt.br.csv) · [Portuguese scale](moodle_scale_0_100_with_intervals_pt.br.csv) | Portuguese variants. |
| [PBL framework](PBLCases/ontoksd_competency_framework.csv) · [PBL scale](PBLCases/moodle_scale_0_100_with_intervals.csv) | PBL-case examples. |

Inspect identifiers, hierarchy, and scale labels before importing into a configured course. Follow the target installation's requirements; these files are not a compatibility guarantee for every Moodle version.

The thesis demonstration examined a selected framework projection, course/assignment associations, and entry/viewing of a manual individual rating. The tree does not reproduce every composition, specialization, qualification, or evidence relationship as an OWL structure.

The scale expresses an example policy. Actual assessment requires evidence, criteria, and procedures for assigning and documenting judgments. Examine which information Moodle retains and which references must be maintained separately.
