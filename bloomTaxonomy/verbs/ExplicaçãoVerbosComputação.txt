Recordação

Explicação do Verbo e Exemplos de Resultados de Aprendizagem

Enumerate - Semelhante a List em usos fora da computação e também possui usos em computação.
1.	Enumerate os passos essenciais do processo da cadeia de eliminação de ameaças de cibersegurança.
2.	Enumerate as etapas no ciclo de vida de desenvolvimento de software (SDLC).
3.	Enumerate os valores de uma coleção em um conjunto de dados.

Reference - Adiciona uma habilidade não incluída diretamente na lista original de Bloom.
1.	Reference múltiplas Publicações Especiais NIST em um relatório de análise de risco cibernético.
2.	Reference fontes de códigos reutilizados como comentários dentro de um programa de computador.

Compreensão

Explicação do Verbo e Exemplos de Resultados de Aprendizagem

Annotate - Anotar claramente diagramas é necessário em tarefas de computação, como projetar fluxos de sistemas e redes.
1.	Annotate um gráfico de ataque no contexto de modelagem de ameaças cibernéticas.
2.	Annotate um diagrama de rede com os nomes dos componentes.

Aplicação

Explicação do Verbo e Exemplos de Resultados de Aprendizagem

Backup - Tarefa comum em computação, especialmente em administração de sistemas e segurança de dados.
1.	Backup vários arquivos e pastas locais ou remotos em um volume de backup.
2.	Backup dados marcados para um local remoto usando um script de automação.
Build - Comumente usado em várias áreas da computação, como sistemas operacionais, TI, programação de sistemas.
1.	Build um modelo de aprendizado de máquina para detectar intrusões na rede.
2.	Build uma rede multi-roteador funcional usando um script de automação.
Code - Tarefa necessária em muitos aspectos da computação, incluindo a construção de infraestrutura virtualizada.
1.	Code um programa em Python a partir de um fluxograma fornecido.
2.	Code uma orquestração de infraestrutura em nuvem usando uma linguagem de script.
Compile - Tarefa comum no desenvolvimento de software, especialmente ao codificar em linguagens compiladas como C e C++.
1.	Compile um programa usando a interface de linha de comando.
2.	Compile um código de baixo nível para um sistema operacional específico.
Compute - Tarefa comum em ciência da computação.
1.	Compute probabilidades condicionais.
2.	Compute resumos de mensagens de arquivos salvos usando vários algoritmos de hash.
Configure - Tarefa comum no mundo real em administração de sistemas, redes e cibersegurança.
1.	Configure um sistema operacional baseado em UNIX para fortalecê-lo.
2.	Configure um firewall para bloquear ou permitir tráfego com base em endereços IP e números de porta.
Connect - Necessário em redes, configuração de sistemas e outros ambientes de troca de informações.
1.	Connect dois sites remotos usando uma tecnologia de tunelamento.
2.	Connect vários roteadores de filiais a um roteador da sede usando redes privadas virtuais.
3.	Connect uma estação de trabalho a um roteador para configurar o roteador.
Decrypt - Comumente exigido para objetivos de segurança da informação.
1.	Decrypt um texto cifrado usando a técnica criptográfica apropriada.
2.	Decrypt um e-mail recebido usando uma chave privada.
Deploy - Tarefa comum em computação.
1.	Deploy um pipeline de aprendizado de máquina para alcançar um algoritmo bem-sucedido.
2.	Deploy várias instâncias de uma máquina virtual de template.
Document - Tarefa comum em computação, inclui documentação de código-fonte, bem como documentação de sistemas.
1.	Document os processos de um sistema de informação em vários níveis de detalhe.
2.	Document um projeto para controle de versão, acompanhando o ambiente de software.
Encrypt - Tarefa comum em computação, com ênfase em cibersegurança.
1.	Encrypt arquivos ou pastas usando uma ferramenta de criptografia adequada.
2.	Encrypt dados dos usuários de um computador usando uma ferramenta de criptografia RSA.
Graph - Verbo usado em estruturas de dados e algoritmos, bem como em ciência de dados e análises.
1.	Graph um conjunto de dados usando um tipo de gráfico apropriado.
2.	Graph um problema combinatório usando busca em profundidade e largura.
Install - Tarefa comum em computação, especialmente em administração de sistemas.
1.	Install um patch de software fornecido.
2.	Install um motor docker em um sistema operacional específico.
3.	Install um dispositivo de firewall de hardware em uma rede.
Iterate - Tarefa comum em linguagens de programação e muitas áreas de computação.
1.	Iterate por uma lista em uma linguagem de programação específica.
2.	Iterate um algoritmo de aprendizado de máquina e indique quantas vezes os parâmetros do algoritmo são atualizados.
Map - Verbo comum em TI e programação.
1.	Map um diagrama de relacionamento de entidades para tabelas em um banco de dados relacional.
2.	Map uma pasta compartilhada atribuindo uma letra de unidade.
Measure - Verbo comum em TI e ciência da computação.
1.	Measure o desempenho dos algoritmos em termos de tempo e espaço.
2.	Measure o tempo de ida e volta (RTT) entre dois servidores.
Provision - Tarefa comum em computação em nuvem e áreas de DevOps.
1.	Provision recursos em um ambiente virtual.
2.	Provision equipamentos de nuvem com software ou serviços para usuários/clientes.
Randomize - Verbo usado em algoritmos, ciências de dados e áreas de cibersegurança.
1.	Randomize números em um algoritmo para simular comportamento aleatório.
2.	Randomize um algoritmo de criptografia usando um grau de aleatoriedade em sua lógica ou em um procedimento.
3.	Randomize senhas iniciais fortes para novas contas de usuário em um sistema.
Recover - Tarefa comum em computação.
1.	Recover arquivos de um sistema operacional como uma aplicação de forense.
2.	Recover dados com base em um termo de pesquisa fornecido, a partir de um sistema com imagem.
Restore - Tarefa comum em computação.
1.	Restore arquivos e pastas de um volume de backup para um drive/pasta local ou remoto.
2.	Restore código para um programa ou aplicação a partir de uma versão anterior do software usando controle de versão.
Schedule - Tarefa de computação com múltiplas aplicações, especialmente em TI.
1.	Schedule backups para atender às políticas de gerenciamento de dados de uma organização.
2.	Schedule etapas em uma avaliação de cibersegurança para um cenário específico.
Store - Tarefa comum em computação.
1.	Store dados de forma segura na nuvem.
2.	Store dados e software de maneira segura em um local externo.
Train - Usado em aprendizado de máquina e ciência de dados, bem como em outras áreas da computação.
1.	Train um modelo de predição usando dados online para melhorar sua precisão.
2.	Train um modelo de aprendizado de máquina com dados armazenados.
3.	Train usuários a identificar e-mails de phishing.
Virtualize - Verbo de ação em vez de "usar virtualização".
1.	Virtualize componentes/recursos nos níveis de servidor e cliente para um cenário específico.
2.	Virtualize uma implantação de aplicação para um cenário específico.


Analisando

Verbo | Explicação e Exemplos de Resultados de Aprendizagem

Articulate - Permite um nível cognitivo mais profundo em comparação com outros sinônimos de Bloom, como Explain e Describe.
1.	Articulate uma estratégia de teste para uma função específica.
2.	Articulate questões legais, autoridades e processos relacionados a evidências digitais.
Automate - Tarefa comum nas disciplinas de computação, exigindo análise prévia.
1.	Automate uma função de usuário, como gerar uma fatura eletrônica ou gerar uma mensagem de erro/alerta.
2.	Automate uma resposta inicial a um incidente de segurança para um cenário específico.
Contextualize - Permite uma compreensão mais profunda dos conceitos de computação estudando o contexto que envolve determinados cenários.
1.	Contextualize vulnerabilidades de segurança para um software específico dentro de um cenário determinado.
2.	Contextualize aspectos sociais e profissionais da computação com relação aos códigos de conduta ética.
Correlate - Analisa a relação entre vários conceitos de computação e o impacto que têm uns sobre os outros.
1.	Correlate o custo de recursos de computação com a melhoria da segurança.
2.	Correlate privacidade, segurança e confiança para um cenário específico.
Detect - Tarefa comum, especialmente em cibersegurança.
1.	Detect uma possível vulnerabilidade em um código-fonte específico.
2.	Detect uma instância de compartilhamento falso.
Generalize - Permite um nível cognitivo mais profundo em comparação com sinônimos de Bloom, como Summarize e Explain.
1.	Generalize as tarefas específicas realizadas por um sistema de ponto de venda.
2.	Generalize vulnerabilidades de segurança em várias estruturas de dados.
Model - Tarefa comum em computação, usa um verbo de ação em vez de "usar modelagem".
1.	Model um problema empresarial matematicamente ou com um algoritmo.
2.	Model um problema do mundo real usando grafos e árvores, como representar uma topologia de rede ou a organização de um sistema de arquivos hierárquico.
Monitor - Tarefa comum para prevenção de anomalias e descoberta de erros em muitas disciplinas de computação.
1.	Monitor o tráfego de rede para vulnerabilidades de segurança.
2.	Monitor controles de entrada em um ponto final para evitar a inserção de dados inválidos ou errôneos no sistema.
3.	Monitor a identidade de usuários ou grupos que solicitam acesso a recursos sensíveis.
Predict - Tarefa comum de análise e tomada de decisão aplicável a muitos projetos de computação e tecnologia.
1.	Predict a saída de um algoritmo após ter sido treinado em um conjunto de dados históricos e aplicado a novos dados.
2.	Predict o custo e os benefícios de um plano de recuperação de sistema.
3.	Predict quais fatores de gerenciamento, organização e tecnologia são responsáveis pelas dificuldades em construir sistemas eletrônicos de registros médicos em uma organização.
Simulate - Verbo comum aplicável ao planejamento, análise e teste em disciplinas de computação.
1.	Simulate uma resposta de recuperação de desastre.
2.	Simulate o papel do pessoal em um ambiente de trabalho de um grupo empresarial.
3.	Simulate o uso de dispositivos móveis durante o teste e prototipagem de aplicações web.
Trace - Tarefa comum aplicável a muitas tarefas de computação, administração de sistemas, redes e cibersegurança.
1.	Trace o valor de uma variável à medida que ele muda ao longo de um módulo de código.
2.	Trace uma lista anexada ou vinculada a pessoas que não têm permissão para acessar qualquer parte ou função do sistema.
3.	Trace uma atividade para detectar a condição que cria um deadlock.
Translate - Tarefa comum em programação, sistemas de informação, redes e segurança.
1.	Translate um problema empresarial em uma solução de inteligência artificial e ciência de dados.
2.	Translate uma especificação de design de sistema em código de programa de software.
3.	Translate comunicação escrita para comunicação oral eficaz.
Update - Tarefa comum em computação.
1.	Update um modelo baseado em dados para um cenário específico.
2.	Update os recursos de um site para atender às necessidades de informação de uma organização ou dos usuários.
3.	Update software para incluir novos recursos.

Avaliando

Verbo | Explicação e Exemplos de Resultados de Aprendizagem

Adapt - Tarefa comum nas disciplinas de computação.
1.	Adapt uma estratégia de defesa de rede a uma nova configuração de rede.
2.	Adapt uma funcionalidade de script para atender a uma função ou tarefa específica.
3.	Adapt software aos padrões da indústria em constante mudança.
Administer - Tarefa comum em sistemas de informação, redes e segurança.
1.	Administer máquinas virtuais que atendem uma grande base de usuários.
2.	Administer um sistema de informação para um negócio local, como um consultório médico, supermercado ou restaurante de fast food.
3.	Administer um servidor web.
4.	Administer ferramentas e técnicas para projetar e implementar uma solução técnica para um processo de sistema.
Debug - Verbo usado na depuração e verificação de erros; tarefa comum em várias disciplinas de computação.
1.	Debug um segmento de código específico.
2.	Debug um problema comum de impressão.
3.	Debug um diagrama de relacionamento de entidades de um banco de dados para identificar anomalias.
4.	Debug software utilizando técnicas apropriadas.
Decide - Verbo comum usado na avaliação das melhores práticas em diversas áreas da computação.
1.	Decide entre vários métodos apropriados para proteger uma rede sem fio.
2.	Decide sobre a resolução adequada para uma solicitação de suporte técnico.
3.	Decide sobre as melhores práticas para segurança ao trabalhar com redes e terminais.
4.	Decide sobre a melhor estrutura de dados para um cenário específico.
Optimize - Meta comum em computação.
1.	Optimize um segmento de código usando funções rápidas.
2.	Optimize o fluxo de rede configurando Listas de Controle de Acesso (ACLs) em portas de firewall.
Prioritize - Possui múltiplos usos possíveis em computação, além de habilidades interpessoais.
1.	Prioritize um algoritmo de busca usando uma estrutura de dados, como heaps binários.
2.	Prioritize o tráfego de rede habilitando funcionalidades de qualidade de serviço.
3.	Prioritize tarefas diárias e semanais para realizar o trabalho crítico e cumprir os prazos.
Prove - Útil em ambientes matemáticos e forenses.
1.	Prove teoremas elementares sobre probabilidade.
2.	Prove a presença de uma vulnerabilidade de segurança em dispositivos finais.
Validate - Habilidade útil em várias disciplinas de computação.
1.	Validate a segurança de software dentro de um plano de teste específico.
2.	Validate um cluster de servidores utilizando uma ferramenta de sistema apropriada.





Criando

Verbo | Explicação e Exemplos de Resultados de Aprendizagem

Collaborate - Habilidade interpessoal útil ao interagir com colegas de computação e usuários finais.
1.	Collaborate com membros da equipe para produzir um artefato computacional.
2.	Collaborate com colegas de equipe e usuários para conduzir uma análise de necessidades para um sistema de ponto de venda.
Compose - Habilidade integrativa útil; mais flexível do que Program.
1.	Compose uma nova classe usando princípios de orientação a objetos para suportar uma nova funcionalidade em um sistema de software.
2.	Compose scripts que rodem sem interação direta.
Generate - Habilidade útil para desenvolver conteúdo a partir de dados ou ferramentas existentes.
1.	Generate relatórios significativos a partir de vários conjuntos de dados.
2.	Generate estatísticas relevantes a partir de dados em planilhas usando funções apropriadas do Microsoft Excel.
Program - Tarefa comum em computação.
1.	Program uma rotina que inicia segmentos de código em vários dispositivos quando uma condição específica é atendida.
2.	Program uma rotina automatizada que pausa o controlador de irrigação inteligente quando a precipitação local excede um determinado limite.
Script - Tarefa comum em computação; mais específica que Program.
1.	Script um algoritmo para realizar a verificação de formulário usando correspondência de padrões e expressões regulares.
2.	Script comandos para instanciar recursos virtuais.
Secure - Tarefa comum em todas as disciplinas de computação.
1.	Secure uma transação entre um navegador e um servidor web.
2.	Secure uma rede local contra ataques de negação de serviço.
Visualize - Habilidade integrativa útil com certas ferramentas de computação.
1.	Visualize um modelo de dados usando bibliotecas conhecidas para análise de dados.
2.	Visualize padrões de acesso a um sistema para rastrear um intruso.
